iPhone, iPad & Mac

Nothing to download. Open the web app in Safari and add it to your home screen / Dock. It then behaves like a normal app and keeps working offline.

Open the web app
  1. iPhone / iPad: open the web app in Safari → Share → Add to Home Screen → Add.
  2. Mac: Safari → File → Add to Dock (macOS Sonoma or newer), or install from the address bar in Chrome / Edge.
  3. Log in once inside the installed app — it keeps its own login.

Add it from the web app page itself, not from this page, or the icon will reopen this page.

Background sync

From version 2.41, anything you recorded without a connection — registrations, class attendance and call responses — uploads on its own once your phone is online again, usually even if the app is closed (not if you force-stop it). It also keeps your calling list and class data up to date. Android decides exactly when background work runs, so battery-saver modes can delay it a little.
